# Woways Website

Public marketing site for **Woways Private Limited** — *Your Additional Executive Partner*.
Execute. Grow. Transform.

A fast, static, multi-page site: an executive execution partner (Sales, Marketing, Operations, HR, Technology), a growth ecosystem connecting companies with talent ("Wowers"), and a portfolio of five live products.

## Pages
- `index.html` — Home
- `companies.html` — For Companies
- `wowers.html` — For Wowers
- `services.html` — Services
- `about.html` — About
- `contact.html` — Contact

## Products (external portals)
- Talent Ignition — https://talentignition.in
- Student Mentor — https://studentmentor.co.in
- College Macha — https://collegemacha.com
- Bispun — https://bispun.com
- Performance Portal — https://woways-performance.vercel.app

## Run locally
No build step. Serve the folder and open the site:

```bash
python -m http.server 8090
# then open http://localhost:8090
```

## Tech
- Static HTML + Tailwind (CDN) + Google Fonts (Syne, Hanken Grotesk) + Material Symbols
- Scroll-reveal animations, responsive, WCAG-minded (skip link, alt text, focus states, reduced-motion)
- `build.py` regenerates all pages from one shared template (header, footer, sections)
